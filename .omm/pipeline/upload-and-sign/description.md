In the browser (apps/web/lib/publish/publish-flow.ts, components/publish/publish-form.tsx): the file is checked (a PDF, at most 15 MB), a short-lived signed URL comes from the server (requestUpload, rate-limited per IP), the PDF goes straight to Pinata, which gives its CID, the wallet, loaded when the visitor clicks Connect (components/wallet/wallet-runtime.ts), switches to Base Sepolia if needed and signs { cid, contextGraph, deadline } (EIP-712, no gas), and submitPaper checks it and sends labstrail/paper.submitted. The page then follows the paper until it is minted.
