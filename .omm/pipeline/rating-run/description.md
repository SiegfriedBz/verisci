The rate-paper function (workflows/src/rating/rate-paper.ts), a singleton per request id with 300 minutes: it checks the request, checks the target is a paper LabsTrail published, then reads the R-KA's state and does only what is left. Each part of the score (the PDF link with the title and abstract, the text, the field check, Gemini's answer) is kept across attempts once it came back, which wait 2, 5, 15, 30, then 60 minutes: the field check runs once a run, and the scorer is asked once per attempt until it answers (ADR 0018). Once the oracle answers, an alert-orphan step alerts on an R-KA the contract will never record (the request cancelled meanwhile, or gone), an alert-oracle-moved step on one an oracle move may leave unrecorded, and for a settled request a notify step sends one activity message, each from a step of its own (ADR 0038); a run that never read the paper looks it up for the message first (find-paper). Started by the webhook's intake, the reconciler, or locally the page.
