On chain: anyone calls RatingController.requestPhase1(targetUal), paying only gas on testnet (ADR 0015), from a paper's page with their wallet, which the Rate button loads on its first click (components/wallet/wallet-runtime.ts); the contract records the request as pending under a new request id and emits Phase1Requested. Deployed, the Alchemy Notify webhook delivers that log to /api/webhooks/alchemy, whose intake sends labstrail/rating.requested (ADR 0017); locally, the paper's page has the server announce the request from its receipt (or the rate-paper dev script sends the event, and post-webhook posts a signed delivery to the route). The reconciler sends the event again for a request pending over 4 hours (ADR 0020). The oracle later fulfils it with the score and the R-KA's UAL, or cancels it.
