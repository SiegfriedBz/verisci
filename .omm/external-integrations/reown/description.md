Reown AppKit with wagmi (REOWN_PROJECT_ID, read from the server's settings at request time): connects the visitor's wallet on Base Sepolia, and locally on Anvil too, for ratings (ADRs 0034, 0036); asks it to sign the submission, and sends a rating request (requestPhase1) from it. It loads only when used: components/wallet/wallet-runtime.ts, the only module importing AppKit and wagmi, is reached through import() when the pointer, focus or a touch reaches a wallet button, on a wallet action, or once the page is idle when the browser keeps AppKit's connected status; no page calls Reown's or Coinbase's servers before then. Loading it fetches AppKit's settings from Reown (a wallet action waits for them up to 8 seconds) and sends Reown AppKit's start-up event, and each connection sends its connection event, whatever AppKit's analytics setting (ADR 0041). Coinbase's two sign-ins (Base Account, Coinbase Wallet) are the runtime's own connectors, with their SDKs' analytics off. AppKit's vanilla set-up and wagmi's actions share the adapter's config, with no React provider. The wallet window names LabsTrail with lib/site.ts's SITE. Without a project id the pages still render and say the wallet is not set up.
