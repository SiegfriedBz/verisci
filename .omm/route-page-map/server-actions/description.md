app/actions.ts: requestUpload (a short-lived signed Pinata upload URL, limited per connection), submitPaper (checks the signed submission, limited per signing address, and sends labstrail/paper.submitted), and announceLocalRating (locally only: the server reads a rating request's log from Anvil and sends labstrail/rating.requested, since no webhook watches Anvil, ADR 0036). Each returns a typed answer the page turns into a message; a service that gives no answer is named in the server log (upload-url-unavailable, submit-unavailable, rating-announce-unavailable).
