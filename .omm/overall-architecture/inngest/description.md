Inngest runs the workflows: it receives events (labstrail/paper.submitted, labstrail/rating.requested), runs the crons (reconcile-ratings every 30 minutes, check-health every hour), sends inngest/function.failed for a run that failed for good and inngest/function.cancelled for one cancelled, past its time budget or by hand (both of which alert-on-failure takes), calls the functions the web app serves at /api/inngest, and memoizes each step's result so a retry or a replay redoes only what is left. Locally its dev server; deployed, Inngest Cloud's free plan, one environment per deployment (ADR 0005).
