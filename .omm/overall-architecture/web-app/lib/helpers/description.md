The helpers at apps/web/lib's root: web-env.ts (the app's own settings, validated with defineEnv, with Anvil's URL and contract read locally for ratings, and the addresses Vercel gives a deployment for the site's own links), server.ts (the upload limits, built once from those settings), site.ts (SITE: the name, the home page's title, the description that names LabsTrail's field, the one-sentence definition, the repo and the maintainer, read by the metadata, the structured data, the share cards, the footer and the wallet window), theme.ts (the script that sets the theme before the first paint), shorten.ts (short addresses and CIDs), utils.ts (shadcn's cn) and empty-module.ts (an empty module next.config.ts puts in place of one the bundle must not load, docs/domain.md → Next.js).
