src/site/: the services the web app's server code calls. upload.ts (getUploadService): a signed Pinata upload URL, a submission checked and sent as labstrail/paper.submitted, a paper's status from the DKG node and the publish run (runs.ts reads the run's state from Inngest's API), with a minted paper's record and, read alongside it, its mint time (publishedAt), and the published papers list read from the graph with each signature checked (papers.ts). ratings.ts (getRatingService): a paper's rating requests on the environment's contracts, current and past, or locally the Anvil one; one rating with its stage from its R-KA on the node or its R-KA's record; each listed paper's summary (summariseRatings, the rule the list and the paper page share); and locally the announce of a request from its receipt. Its chain client (chain.ts, createSiteChainClient, which upload.ts shares) sends the reads made together as one Multicall3 call, gives each call 5 s and asks a failed one once more a second later; a listed paper whose ratings take over 6 s is unknown. webhook.ts (getWebhookIntake): the Alchemy Notify webhook's intake, which checks the delivery's HMAC over the raw body and sends one rating event per request log (ADR 0017).
