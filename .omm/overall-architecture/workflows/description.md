The Inngest workflows and the services the site calls (packages/workflows/): the publish run (a PDF in LabsTrail's field becomes a Target KA), the rating run (a paper is scored and its R-KA minted), the oracle function (every fulfil and cancel transaction, one at a time), the reconciler (a cron that restarts requests pending too long), the alerts (Telegram notifications, an alert on every failed run, an hourly health check), the shared PDF reader and Gemini call, and the site services (upload URLs, submissions, a paper's status, the papers list, its ratings: a paper's requests, one rating's progress, each paper's summary, and locally the announce of a request; and the Alchemy Notify webhook's intake). Logic takes its step tools and adapters as arguments, so tests run it with fakes; src/functions.ts builds the real ones.
