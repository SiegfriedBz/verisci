submit-paper.ts: the server side of a submission, before any run. It verifies the signed CID, checks the file is pinned and public on Pinata, unpins one that is not a PDF when no asset points at it (ADR 0010), and sends labstrail/paper.submitted. Returns a typed refusal for every expected problem. A service that gives no answer (the chain RPC, Upstash, Pinata, Inngest) is logged once as submit-unavailable: <service>: <what came back>, the error described by failure.ts.
