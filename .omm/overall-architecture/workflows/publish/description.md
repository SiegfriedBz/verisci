src/publish/: the publish-paper function (a singleton per CID) that turns a submitted PDF in LabsTrail's field into a Target KA (ADRs 0010, 0037), with what it uses: the submission check (signature, deadline, graph), GROBID's header parse with the text's opening, and the field check. Beside it, what the site service uses before a run starts: submit-paper (the server-side check that sends the event) and the Pinata adapter. The pipeline perspective shows the run's steps.
