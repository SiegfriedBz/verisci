src/rating/: the rate-paper function (a singleton per request id) that scores a requested paper, mints its R-KA and has the oracle fulfil or cancel the request (ADRs 0011, 0018, 0020); the scorer's Gemini call; the oracle-transaction function that sends every oracle transaction one at a time and checks receipts in later steps (ADR 0019); the reconcile-ratings cron, every 30 minutes, which sends the event again for a request pending over 4 hours (reconciler.ts), and the pending reads it shares with the health check (pending.ts); the event builder for labstrail/rating.requested; and contracts.ts, the environment's contracts (current and past, or locally the Anvil one), which the rating run, the reconciler and the site's services share. The pipeline perspective shows the run's steps.
