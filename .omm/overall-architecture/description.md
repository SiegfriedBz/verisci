LabsTrail publishes life-science and health papers as Knowledge Assets on the OriginTrail DKG, signed by their submitter's wallet, and rates them in phases whose scores the oracle records on Base Sepolia. It is a pnpm and Turborepo monorepo: a Next.js app (apps/web), five internal packages (env, core, dkg, contracts, workflows), the RPC proxy that runs on the DKG node server (infra/rpc-proxy), and that server's Caddy and systemd configuration (infra/node-server). Packages ship TypeScript source with no build step.
